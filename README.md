# scaphandre-debian

**Retired 2026-08-15: Debian ships scaphandre officially** (1.0.2 in
trixie, 1.0.3 in sid). Install it with:

```bash
sudo apt install scaphandre
```

The versions this repository published to [pkg.haus](https://pkg.haus)
carry suite qualifiers that yield to the official packages as your suite
catches up; there is nothing to uninstall. This repository is archived
and kept for history.
